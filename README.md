A catalogue photograph of an impossible gadget: a sleek matte-black articulated desk lamp, shot like a real e-commerce product photo on a seamless light-grey studio background — switched on, and projecting not light but a solid cone of pure darkness onto the desk. Caught mid-use, its beam falls on the one accessory in the frame, an open book whose pages are swallowed by the dark and completely unreadable, while the desk outside the beam stays warmly lit. A lamp that does the opposite of a lamp's job, aimed at the thing that needs light most; no caption required. The Node program in this repository delivers the photograph: it copies `entry.png` into the output directory and verifies the copy is byte-identical and within the size cap, so every run produces exactly the same entry.

## Run it

```sh
node main.ts
```

It writes `entry.png` into `$MAKEFUN_OUTPUT_DIR` (or `/output` when the variable is unset).
